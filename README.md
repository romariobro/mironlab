# mironlab.ru

Статический персональный сайт Романа Мироничева.

## Публикация через GitHub Pages

1. Загрузить всё содержимое этой папки в корень отдельного GitHub-репозитория.
2. Открыть `Settings → Pages` и выбрать публикацию из ветки `main`, папка `/ (root)`.
3. В поле `Custom domain` указать `mironlab.ru`.
4. Настроить DNS-записи домена по инструкции GitHub Pages.
5. После подтверждения DNS включить `Enforce HTTPS`.

Файл `CNAME` уже содержит домен `mironlab.ru`.
